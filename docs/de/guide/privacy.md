# Datenschutz

KMyBanners hat keinen Server und kein eigenes Konto. Alles läuft zwischen deinem Handy, GitHub und
Bannergress.

## Was öffentlich ist {#was-oeffentlich-ist}

Das Repository deiner Seite, `ingress-banners`, ist **öffentlich**, ebenso die Seite. Jeder kann sehen:

- deinen Agentennamen;
- die Screenshots deiner Missionsmedaillen und das Bild daraus;
- deine Bannergress-Erledigt-Liste;
- auf der Karte, wo du Banner gemacht hast;
- deine Auswahl für die Reihen, die du geprüft hast.

Dein GitHub-Name ist Teil der Adresse der Seite.

## Was auf deinem Handy bleibt {#was-auf-deinem-handy-bleibt}

Die App speichert ihre Anmeldung bei GitHub und bei Bannergress in ihrem eigenen Speicher auf deinem
Handy. **Abmelden** in den Einstellungen löscht die GitHub-Anmeldung.

Der Zugriff auf GitHub gilt für deine öffentlichen Repositorys. Du kannst ihn jederzeit auf GitHub
zurücknehmen: **Settings → Applications → Authorized OAuth Apps → KMyBanners → Revoke**.

## Deine Seite entfernen {#deine-seite-entfernen}

Lösche das Repository auf GitHub: Öffne `ingress-banners`, **Settings**, ganz unten **Delete this
repository**. Ein paar Minuten später ist die Seite weg.

KMyBanners steht in keiner Verbindung zu Niantic Spatial, Ingress oder Bannergress.
