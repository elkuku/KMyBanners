# Privacidad

KMyBanners no tiene servidor ni cuenta propia. Todo va entre tu teléfono, GitHub y Bannergress.

## Qué es público {#que-es-publico}

El repositorio de tu página (`ingress-banners` si no elegiste otro nombre) es **público**, y también la página. Cualquiera puede ver:

- tu nombre de agente;
- las capturas de tus medallas de misión y la imagen hecha con ellas;
- tu lista de completados de Bannergress;
- en el mapa, dónde hiciste banners;
- tus elecciones para las filas que revisaste.

Tu nombre de GitHub forma parte de la dirección de la página.

## Qué se queda en tu teléfono {#que-se-queda-en-tu-telefono}

La app guarda su sesión de GitHub y de Bannergress en su propio almacenamiento en tu teléfono. **Cerrar
sesión** en los ajustes borra la sesión de GitHub.

El acceso de GitHub es para tus repositorios públicos. Puedes retirarlo cuando quieras en GitHub:
**Settings → Applications → Authorized OAuth Apps → KMyBanners → Revoke**.

## Quitar tu página {#quitar-tu-pagina}

Borra el repositorio en GitHub: abre el repositorio de tu página, **Settings**, al final **Delete this repository**.
Unos minutos después la página desaparece.

KMyBanners no está afiliado a Niantic Spatial, Ingress ni Bannergress.
